# Modo «adoptar» (juegos empezados antes de este sistema, como Steal an Egg)

**Solo escribe archivos. No toca el código ni el juego.**
1. **Inventario** con un subagente barato (Sonnet): repasa el repo y, si está abierto, Studio, y apunta cada función
   que ya existe con sus datos, pantallas y assets, y si está terminada, a medias o rota. Va a `bloques/Lista.md`
   (las hechas, marcadas).
2. **Lo que no cumple el sistema nuevo** (código, UI, mapa, 3D, VFX, sonido, animación) va en una lista aparte
   (`bloques/Adoptar.md`). No obliga a nada: cada punto se arregla como un bloque más, solo si compensa.
3. **Se lo enseñas a Álvaro**, que corrige lo mal entendido y decide qué falta para la siguiente versión.
4. Crea `Estado.md` y desde ahí el juego sigue como uno nuevo, en la fase de bloques.
